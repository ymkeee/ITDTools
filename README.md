# ИТД Расширения / ITD Extensions

Коллекция Chrome расширений для социальной сети [ИТД.com](https://xn--d1ah4a.com)

## 📦 Расширения

### 🎨 Avatar Changer
Быстрая смена аватара профиля

**Возможности:**
- Загрузка изображения с компьютера (до 5MB)
- Установка аватара по URL
- Выбор из 12 эмодзи
- Предпросмотр перед сохранением
- Автоматическая загрузка на сервер

**Установка:** `avatar-changer/`

---

### 📊 User Info Extension
Отображение информации о пользователе на странице профиля

**Возможности:**
- Дата регистрации (с часами и минутами)
- Возраст аккаунта (дни/месяцы/годы)
- Перетаскиваемый блок с сохранением позиции
- Плавная анимация появления
- Автоматическое обновление при смене профиля

**Как работает:**
- Автоматически появляется на страницах профилей (`/username`)
- Получает данные через API `/api/users/{username}`
- Не показывается на служебных страницах (`/feed`, `/notifications`, `/settings` и т.д.)

**Установка:** `user-info-extension/`

---

### 🔔 Notifications Changer
Изменение количества уведомлений

**Возможности:**
- Установка любого количества уведомлений (0-9999)
- Перетаскиваемая панель управления
- Сохранение значения в localStorage
- Плавная анимация появления
- Автоматическое применение при каждой загрузке

**Как работает:**
- Перехватывает запрос к `/api/notifications/count`
- Меняет `{"count": 1}` на заданное значение
- Панель управления внизу слева экрана
- По умолчанию: 999 уведомлений

**Установка:** `notifications-changer/`

---

### 🛠️ ITD Tools Extension
Основное расширение с множеством функций

**Возможности:**
- Спам комментариями
- Автопостинг с AI (OpenRouter API)
- Автоответы на комментарии
- Массовые действия (лайки, подписки)
- Инструменты рисования
- Интеграция ITD+ модулей
- Настройки профиля

**Установка:** `extension/`

---

### 🎭 Role Changer
Создание постов с опросами из 100 вариантов "да"

**Возможности:**
- Кнопка "📊 100 "да"" для быстрого создания поста
- Автоматическое создание опроса с 100 вариантами
- Текст поста: "привет артур"
- Вопрос опроса: "пы"
- Множественный выбор включен

**Установка:** `role-changer/`

---

### 👤 Admin Role
Изменение роли пользователя на "admin" (клиентская модификация)

**Возможности:**
- Перехватывает `/api/profile`
- Меняет `"roles":["user"]` на `"roles":["admin"]`
- Подробные логи в консоли
- Поддержка fetch и XMLHttpRequest

**Установка:** `admin-role/`

---

### 🧪 Test Extension
Тестовое расширение с современным UI в стиле Roblox

**Возможности:**
- 4 страницы навигации (Main/Player/Others/Settings)
- Переключатели (toggle switches)
- Слайдеры
- Перетаскиваемое и изменяемое окно
- Шрифт Montserrat
- Серо-розовый градиент (#a8a8a8 → #d4a5d4)

**Установка:** `test-extension/`

## 🚀 Общая установка

1. Открой `chrome://extensions/`
2. Включи **"Режим разработчика"** (справа вверху)
3. Нажми **"Загрузить распакованное расширение"**
4. Выбери папку нужного расширения
5. Готово! Расширение активировано

## 📝 Примечания

- Все расширения работают только на `https://xn--d1ah4a.com`
- Используют Bearer токен из localStorage (`itd_bearer_token`)
- Большинство имеют подробные логи в консоли (F12)
- Сохраняют настройки в localStorage

## 🔧 Технологии

- Manifest V3
- Vanilla JavaScript
- Fetch API перехват
- Chrome Extension API
- localStorage для сохранения настроек

## ⚠️ Дисклеймер

Эти расширения созданы для образовательных целей и тестирования. Используй на свой страх и риск. Некоторые функции (например, изменение ролей) работают только на клиентской стороне и не влияют на серверные данные.
